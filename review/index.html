App Review

RC Pair for App Review

RC Pair pairs an iPhone or iPad with a computer the user chooses, from the device itself. The app sends nothing to us.

This page holds the two sample QR codes and the computer script named in the Review Notes.

Steps 1 to 4 happen on the device, with no computer. Finish step 4 and see Paired first. If you scan a code before that, RC Pair says there is no pairing to send yet.

Sample codes

Scan each code with the Camera app on the device. If you opened this page on the device itself, tap the link under the code instead. Neither link has a receiver behind it, and both use keys whose private halves were thrown away, so nothing sent to them can be read.

A. Private address

RC Pair shows the confirm sheet with the computer name and address. Tap Cancel. Send would fail and the pairing would stay on the device.

rcpair://send?v=1&h=169.254.77.77&p=47820&k=UO0yRrehTB7c_4YVTVzVZasYugWH3L2VLch9qPxh7sk&t=s_x_uHHk1QneBRFoiJcONw&n=App%20Review%20sample

B. Public address

This link points to a public address. RC Pair refuses it and sends nothing.

rcpair://send?v=1&h=192.0.2.10&p=47820&k=usrGcd_uWj5AFSfc0HXVwYJd062Lfm3nT-0RYfeW5W8&t=kUizoXMKi8OVA-hv7VQCdw&n=Public%20address%20test

With a computer

Optional. You need a Mac or Linux computer on the same Wi-Fi as the device, with Python 3.9 or later. The first command below installs the two packages the script uses, cryptography and qrcode.

Download rcpair-receive.py

In the folder where you saved it, run these two commands.

python3 -m venv rc && rc/bin/pip install cryptography qrcode
rc/bin/python rcpair-receive.py --name Review

After step 4, scan the QR code the script shows and tap Send. The script saves the pairing in ~/.rcpair and exits, and RC Pair shows All set.
